# Bulk Datapack

## 概要

このデータパックは、Minecraft に **一括採掘機能** を追加するデータパックです。  
プレイヤーの視点や設定に応じて、複数のブロックをまとめて破壊できます。

チャットUIによる設定メニューを備えており、  
一般プレイヤーは OP 権限不要で使用可能です。  
また、サーバー運用向けにワールド別の使用制限や  
開発者向けのデバッグ機能も用意されています。

サバイバル・建築・整地用途を想定した  
サーバー導入向けデータパックです。

---

## 利用方法

① 初期導入>>=========================================

データパック導入後、以下のいずれかを必ず行ってください。

- ワールドの再読み込み  
- サーバーの再起動  

scoreboard が正常に動作しない場合は、  
以下のコマンドを実行してください。

/reload

(リロードすると "一括モード" と "松明自動設置機能" が offになります)

② 設定メニューの表示方法>>===============================

1: shiftを3~5回押してください (0.25秒間隔)
2: チャット欄に表示された[詳細設定]をクリック

一括採掘を有効にする場合

手順２より[一括モードOFF]をクリック
ON => OFF の場合も1,2の手順を繰り返してください

====================================================

- - - - - - - - - - - - - - - - - - - - - - - - - - -

③ 開発者用>>=========================================


1. 一括採掘のデバッグ機能
・一括実行時に採掘したブロックの値をチャット欄に表示する

手順>>
・shift3回でメニューを開き"一括モード"をONにする (機能起動のため)
・scoreboardコマンドでBulk_modeの値を1~3に設定 (機能起動のため)
・Tagコマンドで"Bulk_debug"を追加 ( /tag @s add Bulk_debug )



2. enecyのデバッグ機能
・enecyで回収されたエネルギー量をチャット欄に表示する

手順>>
・shift3回でメニューから詳細設定で"enecy"を有効にする (機能起動のため)
・Tagコマンドで"enedebug"を追加 ( /tag @s add enedebug )

手順後は指定アイテムを吸収させるとチャットに表示されます



３. ワールド別制限設定

一括モードとトラクターの使用制限などは、以下の function により制御されています。
Bulk v2.1.2\server_Bulk\data\bulk\function\config\wlimit_list.mcfunction (一括破壊)
server_Bulk\data\bulk\predicate\wlimit.json (一括破壊 - 参照ファイル先)
server_Bulk\data\sandput\function\cac\wlimit_list.mcfunction (トラクター)

④ 注意事項>>=========================================

本データパックは、
視点を下向きにした状態で採掘を行うと岩盤を破壊可能です。
（コマンド実行による処理のため、
プラグイン等の保護機能を貫通します）

サーバー導入後、
新規参加プレイヤーが詳細設定を開けない不具合があります。
この場合は、一度サーバーを再起動してください。

⑤ 一部機能の調節方法 >>===============================

本データパックの各機能は ~core.mcfunction が本体となっており、
以下ファイルが調節をしています。

server_Bulk/data/fileloader/function/main.mcfunction (制御ファイル)

各機能は主機能と副機能に分類することができ
副機能は実行しなくても、一括利用を問題なくお楽しみいただけます。

以下は各機能の分類です。

*主機能
・ mining_system:core
・ bulk:core
・ sandput:core
・ status:core

*副機能
・ timecounter:timer/core

(!注意! 主機能の記述順は変更しないでください、正常に動かなくなる場合があります。)

⑥ 現在確認中の不具合 >>===============================

・トラクターにエンティティが乗っているとき
"他のエンティティに乗る" または "sitプラグインの座る動作" を行うと
座っているプレイヤーにも一括採掘が実行される不具合

・一括採掘のワールド制限がうまく動作しない
