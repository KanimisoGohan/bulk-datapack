# server_Bulk - マルチサーバー向け統合システムデータパック

Minecraft Java版（マルチプレイ・イベントサーバー）向けに開発した、大規模統合型データパックのシステム構成および実績紹介です。
※本リポジトリはポートフォリオ（技術実績）公開用のため、ソースコード本体は非公開としています。

## 主な実装機能

### 1. カスタムディメンション管理 (`customd`)
- 資源ワールド（`resouce`）、イベント用ワールド（`event`）、中継エリア（`relay`）など、用途別のカスタムディメンションを生成・制御。

### 2. 独自エネルギー・経済システム (`sandput`)
- プレイヤーの行動や特殊装備に連動するエネルギー（`enecy`）の消費・チャージ・取引システムを実装。
- 独自UI（`dialog`）を用いた直感的な設定メニュー・モード切替機能を構築。

### 3. 採掘システム・一括破壊 (`mining_system` / `bulk`)
- 採掘量に応じたレベルアップ・経験値計算（`calc`）・ステータス表示機能。
- 状況に応じて切り替え可能な複数の採掘モード（`all` / `sep`）を搭載。

### 4. 3Dアニメーション・演出連携 (`animated_java`)
- Animated Javaと連携し、攻撃モーション（`attack1_1`）やスキル演出（`skill1`）、待機モーションをコマンドベースで精密に制御。

### 5. サーバー負荷対策・管理機能 (`cac` / `fileloader`)
- マルチサーバー環境での安定稼働を目的とした、エンティティ制限・ワールド境界制御・距離判定API（`distance`）の実装。

## 技術スタック・使用要素
- **Minecraft Datapack** (`mcfunction`, `predicate`, `dimension`, `dimension_type`, `dialog`)
- **外部ツール連携**: Animated Java / Blockbench
- **開発規模**: 550ファイル以上によるモジュール分割設計
